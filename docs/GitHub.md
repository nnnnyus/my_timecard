# 基本的なコマンド
リポジトリーの作成(初期化)
カレントディレクトリーをGitリポジトリーとして管理するための初期コマンドで.gitが作成される
- git init

ディレクトリー内でファイルが生成されていることを確認する
- ls

コミット関連
①git addで指定されたファイルがコミットの対象になる
　ファイル名か複数ある場合.を使用する
- git add ファイル名
- git add .

②コミットメッセージの入力
- git commit -m 'ここにコミットメッセージを入力'

リモート関連
リモートリポジトリーを、ローカルPC上にクローンする
- git clone リモートリポジトリーのURL　ローカルディレクトリー名

ローカルPC上のリポジトリーを、リモートリポジトリーへアップロードする
- git push

履歴と復元
コミットの履歴を表示する
- git log

指定のコミットIDのコミットから、指定のファイルまたはディレクトリーを復元する
- git restore -s コミットID ファイル名またはディレクトリー名

カレントディレクトリー以下のすべてのファイル状態を言外のインデックスの状態に戻すコマンド
- git restore .
